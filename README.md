# 龍門陣工具箱｜YouTube 鈴聲連動版

版本：YOUTUBE-LINK-ALARM-20260608-15

新增：
- 鈴聲類型可選「內建鈴聲」或「YouTube 網址」
- 可貼 YouTube 影片 / 播放清單網址
- 時間到時顯示「開啟 YouTube 鈴聲」
- 會嘗試自動開啟 YouTube
- 手機有 YouTube Premium 時，背景播放由 YouTube App / 帳號處理
- 內建鈴聲仍可作為提醒備援

注意：
- 網頁不能直接控制 YouTube Premium 權限
- 這版是連動 YouTube App / 網址開啟
- 若瀏覽器阻擋自動開啟，請點「開啟 YouTube 鈴聲」

一定要上傳：
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png
- vercel.json
- README.md
- api/cloud.js
- api/cloud-restv1.js
