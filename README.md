使用方式：
1. 覆蓋 GitHub 7 個檔案
2. 打開 APP → 設定 → 雲端同步與登入 REST 版
3. 直接按「測試雲端連線」
4. 成功後按「重新讀取雲端」
5. 要修改或上傳時，自己輸入管理者 Email 與密碼 → 按「管理者登入」
